🎯 OBJETIVO
═══════════════════════════════════════════════════════════════════════════

Crear un launcher personalizado para TV LG webOS 33 que sea:

    ⚡ MÁS RÁPIDO
       • Input delay < 100ms (vs ~500ms actual)
       • Apps se abren al instante
       • Sin lag en navegación

    🎨 MÁS DIVERTIDO
       • Interfaz estilo Nintendo Wii
       • Menú carrusel colorido
       • Navegación fluida

    📱 FUNCIONAL
       • Acceso a todas las apps de streaming
       • Instalación/actualización de apps
       • Gestor de favoritos

    🔒 SEGURO
       • Sin modificar ROM ni hardware
       • Completamente reversible
       • Solo una app más en webOS


🚀 COMIENZA EN 5 PASOS
═══════════════════════════════════════════════════════════════════════════

Paso 1: PREPARAR PC (30 minutos)
  1. Instalar Node.js 18+
  2. Instalar webOS CLI
  3. (Opcional) Instalar webOS Studio en VS Code

Paso 2: PREPARAR TV (20 minutos)
  1. Settings → Channels → Developer Channel
  2. Activar SSH en Developer Settings
  3. Anotar IP de la TV

Paso 3: EJECUTAR SETUP (5 minutos)
  $ bash setup.sh
  ✓ Instala dependencias
  ✓ Crea estructura de proyecto
  ✓ Genera archivos base

Paso 4: CONFIGURAR CONEXIÓN (10 minutos)
  $ bash configure-tv.sh
  ✓ Verifica SSH
  ✓ Agrega TV a webOS CLI
  ✓ Prueba conectividad

Paso 5: PRUEBA HELLO WORLD (10 minutos)
  $ cd webos-launcher
  $ npm install
  $ npm run install-tv
  $ npm run launch
  ✓ ¡App visible en TV!

🆘 AYUDA & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problema: "webOS CLI no se encuentra"
Solución: npm install -g @webostv/webos-cli
         Reiniciar terminal

Problema: "No puedo conectar a TV"
Solución: 1. Verificar Developer Mode + SSH habilitado
         2. Verificar IP correcta
         3. Reiniciar TV
         4. Ver CHECKLIST_FASE1.md para más detalles

Problema: "npm install falla"
Solución: npm cache clean --force
         npm install

Más ayuda: Ver CHECKLIST_FASE1.md y RECURSOS_REFERENCIA.md
